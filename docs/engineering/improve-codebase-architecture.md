## What it does

Find supported architectural improvements in a requested area. A useful audit can conclude that no refactor is warranted.

## When to reach for it

Type `/improve-codebase-architecture` when you want an architecture audit. This skill is explicit-only.

## Common questions

**Does it force an HTML report or grilling?**

No. Prose or a compact diagram is the default. HTML and a design interview are available when requested.

## It's working if

Findings identify concrete friction, affected callers, and a proportionate correction.

## Where it fits

Use it to assess an area; use [codebase-design](https://aihero.dev/skills-codebase-design) for a selected interface decision. For the available skills, see [ask-matt](https://aihero.dev/skills-ask-matt).
