## What it does

Configure tracker and domain-document routes while preserving working repository conventions. Existing approval is reused for its scope.

## When to reach for it

Type `/setup-matt-pocock-skills` when you want explicit repository setup. This skill is explicit-only.

## Common questions

**Will it ask for every section again?**

No. It resolves only missing material choices, validates the local mapping, and reports live tracker drift without silently changing it.

## It's working if

The repository has usable routes and a valid mapping, with missing live access clearly reported.

## Where it fits

This is a setup tool, not a prerequisite for ordinary work in an already configured repository. For the available skills, see [ask-matt](https://aihero.dev/skills-ask-matt).
