## What it does

Resolve a technical question with primary-source evidence. Ordinary research can return a cited answer without creating files or background tasks.

## When to reach for it

Type `/research` when you want a question that needs source verification. It may also be selected when the requested task fits.

## Common questions

**Does it always create a report and delegate?**

No. It writes durable findings when requested or appropriate under repository policy. Independent research can run in parallel when useful and permitted.

## It's working if

The answer supports the requested decision and distinguishes evidence from uncertainty.

## Where it fits

Use it as a standalone source investigation or to inform a larger task. For the available skills, see [ask-matt](https://aihero.dev/skills-ask-matt).
