## What it does

Stress-test a plan through consequential questions and concrete scenarios. The interview ends when the requested decision is clear enough to act on.

## When to reach for it

Type `/grilling` when you want an explicitly requested design interview. It may also be selected when the requested task fits.

## Common questions

**Must every possible question be answered?**

No. Ask about choices that change the outcome. Routine implementation details can use judgment, and the user can stop the interview.

## It's working if

The conversation resolves material tradeoffs without expanding into unrelated decisions.

## Where it fits

Use it directly or through the interview aliases; implementation follows existing authorization. For the available skills, see [ask-matt](https://aihero.dev/skills-ask-matt).
