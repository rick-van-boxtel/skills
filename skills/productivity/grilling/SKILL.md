# Grilling

Help the user resolve consequential assumptions, constraints, and tradeoffs in the
requested plan. Look up available facts yourself. Ask a manageable set of questions
whose answers would change the decision, and give a recommendation where useful.
Defer dependent questions until their prerequisites are answered.

Use concrete scenarios to expose ambiguity. Do not expand the interview into every
possible branch or require the user to decide routine implementation details.
Summarize the settled decision and remaining uncertainty when the requested scope
is clear enough to act on, or when the user asks to stop.

An interview alone does not authorize implementation. When implementation is
already requested, continue once consequential choices are resolved without
requiring another generic confirmation. Respect existing action boundaries.
