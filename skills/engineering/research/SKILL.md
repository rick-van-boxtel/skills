# Research

Resolve the requested question using the source that owns each important fact:
official documentation, source code, specifications, or verified first-party data.
Distinguish observed facts, inference, and unavailable evidence. Date or version
claims that can change.

Answer with the evidence needed for the user's decision. Stop when the question
is resolved or the remaining uncertainty and its impact are clear. Use parallel
research only for useful independent questions when delegation is permitted.

Write a file only when requested or when durable findings belong in an existing
canonical document under the repository's policy. Ordinary reading does not
require a report file, new task, issue, branch, or publication. Research does not
authorize external mutations.
