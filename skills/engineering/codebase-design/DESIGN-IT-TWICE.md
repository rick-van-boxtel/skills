# Compare alternative interfaces

Use this when a meaningful design choice remains, not for every interface edit.
Frame the current callers, constraints, and difficult behavior. Compare the
simplest viable design with an alternative that changes a consequential tradeoff.
Include a caller example and the complexity each design hides or exposes.

Explore directly or delegate independent alternatives when useful and permitted.
There is no fixed agent count. Keep every proposal within current requirements;
flexibility for imagined future callers is not a benefit by itself.

Recommend the design with the clearest caller contract and least necessary
complexity. Ask the user only about unresolved product choices or meaningful
tradeoffs; routine implementation decisions can proceed under existing authority.
